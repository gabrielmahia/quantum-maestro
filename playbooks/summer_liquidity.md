# Playbook: Summer / Holiday Liquidity
**Pattern:** thin books amplify moves both ways; false breakouts increase.
**Do:** cut size one regime notch below the engine's output; widen expected slippage in cost modeling; prefer the most liquid names only (SPY/QQQ/mega-caps).
**Don't:** read thin-tape moves as regime changes (Recency Guard); chase breakouts without volume confirmation.
