# Playbook: After a Losing Streak (incl. any >=1R loss)
**Rules in force:** COOLDOWN (1 session), CIRCUIT-BREAKER if daily -2%.
**Do:** journal the loss the same day (facts -> decision quality -> lesson); halve size for the next 5 trades regardless of regime; re-read the NO-REPAIR rule.
**Don't:** revenge trade; "win it back" on shorter DTE (the death spiral is: loss -> shorter DTE -> bigger size -> account gone); change the system mid-drawdown - log proposed changes and review them flat.
**Doctrine (Dalio):** Pain + reflection = progress. Pain without reflection = tuition without a diploma.
